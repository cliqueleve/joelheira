# Joelheira · CliqueLeve

Abra `index.html` para conferir a página. O projeto é estático e dispensa instalação ou compilação.

## Configurar a oferta

Edite `produto.js` com o nome oficial, preço em reais, fotos adicionais referenciadas no guia, especificações verificadas e informações de compra. Os CTAs de compra aparecem ao configurar uma URL HTTPS em `checkoutUrl`. Os dois CTAs usam a mesma URL e sincronizam o tamanho quando o checkout documenta um parâmetro para isso. Sem esse parâmetro, a escolha é feita diretamente no checkout.

A galeria já inclui a foto recebida e um recorte da mesma foto. No hero, o fundo original foi recortado. A foto de frente está preservada na galeria.

## Publicar

Envie o conteúdo desta pasta à raiz do repositório dedicado ao produto, mantendo a pasta `assets`. Configure o GitHub Pages para usar a branch escolhida e a pasta raiz. Depois de preencher a oferta, confira os dois botões de compra e o fluxo de tamanhos no checkout real.
